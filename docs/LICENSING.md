# Licensing and commercial exceptions

The maintainer authorized GNU AGPL version 3 for this release. [LICENSE](../LICENSE) contains the exact license. The package identifier is `AGPL-3.0-only`. Preserve the copyright and license notices when redistributing the project, and follow the license's source-sharing obligations when they apply.

Commercial use is permitted under AGPL without a royalty if the user complies with its terms. A company that needs rights outside those terms can request a separate paid commercial agreement from the copyright holder. This repository offers that conversation. It does not grant an exception, establish prices, promise revenue or create a signed commercial contract.

The AGPL includes obligations for modified software used through a network. Its obligations depend on how a particular product combines, modifies or conveys the code. Read the [official license](https://www.gnu.org/licenses/agpl-3.0.html) when evaluating a concrete distribution or service. GNU explains [selling exceptions](https://www.gnu.org/philosophy/selling-exceptions.html). The [Open Source Initiative definition](https://opensource.org/osd) allows commercial use; a rule that every commercial user must pay would be a different source-available licensing model.

The original checkout contained no project license. This is a release decision, not evidence of an earlier license. [Third-party notices](../THIRD_PARTY_NOTICES.md) describe dependencies and excluded dataset assets. A license grant covers only rights the contributor owns. Dependencies retain their own licenses. Raw dataset caches and dataset-derived probe snapshots are not redistributed in the source release.

For future external contributions, obtain any extra permission needed for commercial relicensing before offering exceptions for those contributions. AGPL permission by itself does not transfer their copyrights to the maintainer.
