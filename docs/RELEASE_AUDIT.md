## What works today

The native Rust tensor stores four-byte RGBD tokens and computes exact arithmetic in `Z/391680Z`. Python, C, Rust and the CLI can encode, compute, reshape and save/load bounded files. It is useful for investigating discrete color arithmetic and tensor storage. Native GPU execution, autograd and neural training are absent.

Explicit legacy APIs retain scalar codecs, decoded PyTorch operations, numerical training, checkpoints, multidimensional cubes, Fourier representations and the loopback dashboard. The dashboard executes real bounded inspection operations. No account, guest pass, billing, chat, upload service, Convex database or hosted model provider exists. There is no production database migration.

## Failures and limits

Earlier runs exposed indexing truncation, missing build directories, archive-directory parsing, callback lint errors, dependency advisories and a Rust container patch-version mismatch. Repairs and regressions resolved them. Source changes correctly invalidated intermediate receipts, which were regenerated. One older smoke scan reported 29 path matches. Its fresh replacement passed, with no unsupported claim about the old matches' cause. The first clone failed notice hash validation after line-ending conversion; a new clone passed after the byte-preservation fix. Initial static invocations lacked Ruff and named a nonexistent JavaScript file. The pinned Ruff and actual shipped-script checks passed.

Browser evidence does not establish complete accessibility certification. Fresh builds work independently, but bit-identical compiler output is not claimed. Version locks lack wheel download hashes. The dashboard lacks account authentication and is not approved for public hosting. Historical research is not relabeled as newly reproduced science.

Choose an empty destination repository and enable private vulnerability reporting before publishing. [The release guide](RELEASE_GUIDE.md) provides the prepared push commands. Publication remains a maintainer action. Commercial exception agreements and broader platform claims require separate work.
