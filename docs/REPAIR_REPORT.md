ChromaTensor is a working local research library and dashboard. It stores integer codes, reads official image datasets and actual text, trains models, saves checkpoints, and reloads them for measured inference. Cube Lab calls the Python implementation for creation, turns, slicing, and spectral reconstruction. These are implemented operations with execution evidence.

The September 30, 2026 [review](CODE_REVIEW.md) found 15 correctness and release defects. The repair work addresses every finding and adds checks that reject missing, stale, or inconsistent evidence. The local research release remains the target. Public deployment, broad scientific superiority, and integer-only neural training remain unverified.

All fifteen original review findings passed their repairs before the RGBD token update. That source passed 580 host tests with zero skips, ten acceptance gates and nine local dependency jobs. Its fourteen original defect flags were false. Those successful runs are historical and cannot validate the changed tokenizer, neural RGBD mode or dashboard.

## RGBD token update and verified release evidence

The previous no-argument tokenizer returned palette IDs despite the requested actual color-token contract. The dashboard's `COLOR_` labels also used decimal IDs where readers expected hexadecimal RGB bytes. Default tokenization now stores real uint8 `[N, 4]` RGBD rows. D is the finite FP32 exponent, and decoding needs all four bytes. Explicit vocabularies retain their ID behavior. The optional neural RGBD mode materializes weight and activation bytes while keeping floating-point masters and kernels. [The exact contract and migration](RGBD_TOKENS.md) describes those APIs.

## What the measurements establish

The repaired pilot keeps official MNIST and CIFAR-10 distinct from Tiny Shakespeare and the defined analytic tasks. Each trained record includes a saved checkpoint and real held-out CPU replay inputs. The acceptance verifier reloaded all 89 trained records and repeated their predictions. Six inference-only integer controls complete the 95-record pilot. Both live profiles also operated on saved models.

The sustained procedure trains FP32, INT8, and chroma8 models across four seeds. Every seed divides the 60,000 official MNIST training observations into 48,000 training and 12,000 development observations. The procedure opens the 10,000 official test observations only after all 12 checkpoints finish. Saved IDs, predictions, hashes, and actual monotonic stage samples allow independent verification. Earlier repository experiments already used the official test set. This procedure protects its own final evaluation; it does not make that dataset historically unseen.

The large-tensor comparison uses ten million CPU FP32 values. RGB24 and packed fixed24 each use 30,000,000 payload bytes and 131 metadata bytes. Their payload hashes and decoded values match. RGBD uses 40,000,000 payload bytes and 101 metadata bytes and preserves the sampled FP32 bits. Independent acceptance regenerated the samples and checked the actual files. These measurements establish large-file behavior and actual storage. They do not establish reduced training memory or faster neural execution.

The dashboard storage chart now includes codec metadata in its bits-per-value calculation. The 65,536-entry learned codebook row occupies 35.34384 stored bits per value for one million values. The label reports that measured storage rather than the vocabulary's 16 nominal bits. Palette and centroid metadata count even when they exceed the packed code payload.

Cube checks cover exact integer turns and inverses, numerical reconstruction after missing Fourier coefficients, and six models trained on a defined periodic-field generator. The numeric polar and chromatic spectral controls use the same coefficients and produce identical paired results. Direct RGB reconstruction has lower held-out error in the recorded experiment. Noise controls expose the model's dependence on the training distribution. Arbitrary-data recovery is unsupported.

The dependency checks use fresh Windows virtual environments and independent Linux container dependencies on Python 3.11 through 3.14. A separate Windows job tests the declared minimum dependency set, including Torch 2.3 and torchvision 0.18. Installed inference uses isolated Python with user-site imports disabled. Across the nine jobs, 27 installed CPU controls passed. Eighteen replayed and timed saved floating point models; nine checked finite output from the integer reference. These are nine executed local jobs. The configured GitHub Actions workflow has not run on hosted workers, and the checks do not certify a newly provisioned physical machine or driver installation.

## Claims and remaining limits

I would use this release as a reproducible local research library. The integer storage, finite operators, dataset pipelines, checkpoints, and local dashboard have concrete implementations. The evidence makes their behavior inspectable and repeatable within the tested configurations.

Neural training remains floating point quantization-aware training. It retains master weights, gradients, optimizer state, dense kernels, softmax, and range metadata. Chroma8 has 256 numerical levels but stores three RGB bytes per scalar in its chromatic representation. Those bytes cannot be reported as an eight-bit physical payload. Separate integer inference controls use INT8 weights and INT32 products with floating point scaling and activations.

The measurements give no advantage to color labels. Chroma8 and INT8 controls agree, as do RGB24 and fixed24. The learned RGB encoder has greater reconstruction error than the recorded uniform controls, and codebook attention has higher measured latency than ordinary dot attention. The Fourier representation uses complex128 software kernels and stores a redundant full spectrum for real inputs. It does not establish optical computation or a new number system.

Human screen-reader operation, public hosting, authenticated multi-user operation, production traffic, other hardware, exhaustive hostile-file fuzzing, and broad learned-color superiority remain unverified. They are outside this local release's claims. Extending the project to those uses requires explicit new work and evidence.
