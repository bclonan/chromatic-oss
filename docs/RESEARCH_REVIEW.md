# Research review

Historical research document. Recorded metrics and source identities describe the original checkout. Use [the release audit](RELEASE_AUDIT.md) and the current setup/testing guides for this sanitized candidate. Some original companion artifacts are omitted; regenerate them with the included scripts.

ChromaTensor is an executable research implementation. It stores numerical codes as color channels, preserves their meaning through tensor shape operations, trains quantization-aware PyTorch models, and implements discrete operators. These results establish a working representation and software system. They do not establish that color labels improve numerical computation.

The new default tokenizer stores actual RGBD byte rows. The rows preserve finite FP32 bits without retaining original floating values. Current source `69eb8feebdc26d4e72bd1160ed7e5cf695d5035a65f62edebc1a061061ba1fba` passed 702 host tests with zero skips in 75.94 seconds and a separate million-value independent NumPy byte oracle and cold-process file decode. That file contains 4,000,000 payload bytes and 295 metadata/container bytes. Its 32.00236 stored bits per value gives no payload compression over FP32. [The exact token contract](RGBD_TOKENS.md) and [proof receipt](history/results/rgbd-token-verification.json) define what passed.

The current pilot, sustained study, token proof, exact-wheel matrix and installed browser checks have fresh source-bound receipts. All eleven [acceptance gates](history/results/acceptance.json) passed. Optional RGBD neural forward bytes keep floating-point masters and kernels; byte-valued tokens alone do not establish a new arithmetic system.

The September 30, 2026 [code and system review](CODE_REVIEW.md) records defects in the version originally reviewed. The current [pilot record](history/results/latest.json), run `bench-20261001T041728137087Z-970bb8116dbc`, contains 95 model records across seeds 7 and 23, 92 precision rows, and saved-checkpoint CPU replay probes for all 89 trained records. The remaining six records are inference-only integer controls tied to their source FP32 checkpoints. The probes require bit-exact CPU predictions on small real held-out input batches. They preserve the original GPU task metrics; final independent acceptance replay passed for all 89 saved models and both live profiles. [The review checklist](REVIEW_CHECKLIST.md) tracks the software and evidence repairs.

The original causal defect came from estimating an activation range over the entire tensor. Future positions could change the scale for earlier positions despite the attention mask. Neural activation quantizers now estimate a separate range along the final feature dimension. Tests cover changed future inputs, full sequences and prefixes, query chunks with explicit masks, and future-input gradients in the actual language model and both attention modes. The original deterministic reproductions now report zero change in earlier outputs. These checks support the current causal behavior within the tested APIs and configurations. The earlier quantized language and attention records are historical evidence and should not be pooled with the repaired run.

Execution and storage still need precise names. Training retains floating point master parameters, floating point dense kernels, and ordinary optimizer state. Activation range metadata uses two FP64 values per feature vector, or 16 bytes. A singleton feature vector reconstructs exactly through its stored offset, so it provides no evidence of low-bit compression. Chroma8 has 256 numerical levels but its RGB payload occupies 24 physical bits per scalar, before range metadata and retained inspection buffers. Nominal quantization bits, RGB payload, live parameter bytes, checkpoint bytes, and deployed execution precision answer different questions. The reports keep these costs separate.

The paired numerical controls are decisive. Chroma8 relabels the same levels as INT8, and RGB24 packs the same index as fixed24. In the repaired pilot every equal-quantizer paired scalar, MNIST, CIFAR, and language metric difference is zero. Those comparisons establish equivalent numerical behavior. They provide no accuracy benefit from the labels. Physical storage comparisons must also include payload layout and metadata, rather than treating an 8-bit level count as an 8-bit RGB buffer. Circular hue removes a linear phase discontinuity, but the numerical circular control has the same geometry. Its paired periodic result is also identical.

The attention experiment works, but the recorded results favor ordinary attention on cost. Across the two current pilot seeds, mean validation MSE is 0.00396 for FP32 dot attention, 0.00394 for chroma8 dot attention, and 0.00464 for codebook attention. Mean inference batch time is about 1.52259 ms, 8.94265 ms, and 14.28647 ms respectively on the recorded GPU. Two seeds do not establish a population accuracy difference. The codebook path computes nearest assignments and similarity tables with floating point operations; softmax and value accumulation also remain floating point. Training computes a dot-product gradient surrogate. This implementation demonstrates an alternate attention rule, with a measured latency penalty in this experiment.

The jointly trained RGB encoder and decoder also run and reload. Their held-out scalar MAE is 0.0207 in the pilot. Uniform8 achieves 0.00195 on the same observations, and uniform24 achieves about 0.0000000300. The learned codec therefore does not justify its error or extra model costs here. Learned centroid tables are scalar vector quantization. A palette can make those assignments inspectable, but color labels and palette plots do not establish semantic organization or useful color geometry.

Integer table gathering and grid addition avoid reconstructing one floating scalar per input value. Their table construction still uses floating point, and the neural models still use floating point kernels. Fitting all 256 input pairs of a 16-token operator establishes that the finite table is learnable. It does not show generalization to a large alphabet, a new arithmetic system, or a scalable replacement for ordinary matrix multiplication.

The current source-bound [sustained research run](history/results/release-research.json) is complete, run `release-research-20261001T042315415709Z-78aae1bc39ad`. Its fixed procedure trained 12 FP32, INT8, and chroma8 models for 20 epochs across seeds 7, 23, 41, and 59. Each seed split all 60,000 official MNIST training images into 48,000 training and 12,000 development images, with saved disjoint sample IDs. The procedure evaluated all 10,000 official test images after all 12 checkpoints finished. Mean final test accuracy was 97.5175% for FP32 and 97.6075% for both INT8 and chroma8. INT8 and chroma8 have identical final prediction file hashes for every seed. The observed 0.09 percentage point difference from FP32 is a result of this fixed quantization-aware experiment, not evidence that color labels improve accuracy or a general superiority claim. Earlier repository experiments already used the official MNIST test set. Withholding it within this procedure does not make it historically unseen evidence.

The sustained run also encoded ten million CPU FP32 values. RGB24 and packed fixed24 each used 30,000,000 payload bytes and 131 metadata bytes, totaling 30,000,131 bytes. Their payload checksums, codes, and decoded values match. RGBD32 used 40,000,000 payload bytes and 101 metadata bytes and recovered the sampled FP32 bit patterns exactly. Peak process RSS was 2,816,032,768 bytes, with an increase of 1,266,499,584 bytes during the tensor check. This establishes the measured large-tensor storage and round-trip behavior. It does not establish a neural memory, integer-kernel, or speed advantage.

The original repair checklist and RGBD update are complete. The scientific claims below remain unverified.

The scientific claims still requiring evidence are specific:

- Learned color geometry outperforms established scalar, vector, or residual quantizers under matched total storage and compute costs.
- Results generalize beyond the tested models and distributions, with enough independent trials to estimate uncertainty and fresh test data protected from model selection.
- A deployed chromatic backend reduces latency, memory traffic, energy, or cost on specified hardware. The current floating point reference kernels do not establish that result.
- Entirely integer or chromatic neural training is possible with the same behavior. Quantization-aware floating point training does not prove it.
- The representation supplies a novel number system, optical computation, or a research breakthrough. Working code and finite tables do not establish those claims.

The next useful comparison is a preregistered evaluation of learned color coordinates against conventional quantizers, including every metadata byte and every encoder, decoder, and operator cost. Use new distributions and fresh final test data. Keep equivalent relabelings as controls. A result that loses to those baselines is still useful evidence, and the current codec and attention results should remain visible.
